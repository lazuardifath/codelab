Quick recap
Data = fakta mentah. Informasi = data yang diolah.

2. Apa itu basis data?

Basis data (database) adalah kumpulan data yang disusun secara terstruktur agar dapat disimpan, dicari, diperbarui, dan digunakan bersama.

LEMARI ARSIPfolder dan berkas
diatur menjadi
DATABASEtabel, baris, kolom

Tanpa database

  • file mudah ganda
  • versi data membingungkan
  • pencarian tidak konsisten

Dengan database

  • data terstruktur
  • aturan akses jelas
  • pembaruan konsisten

4. Database dan DBMS

DBMS (Database Management System) adalah perangkat lunak untuk membuat, menyimpan, mengubah, mencari, dan mengamankan database.

USER↓APPLICATION↓DBMS↓DATABASE

Contoh DBMS: MySQL, PostgreSQL, MariaDB, SQL Server, Oracle Database, dan SQLite.

6. Guided exercise

Dalam sistem akademik, admin membuka aplikasi, aplikasi meminta data kepada DBMS, dan DBMS mengambil data dari database.

Lihat pembahasan
  • Data: NIM, nama, kode mata kuliah, nilai.
  • Informasi: daftar mahasiswa yang lulus.
  • Aplikasi: portal akademik.
  • DBMS: perangkat lunak pengelola database.
