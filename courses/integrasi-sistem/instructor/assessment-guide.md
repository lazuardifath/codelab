# Assessment Guide

Gunakan bobot RPS yang ditetapkan dosen. Rubrik modul di CodeLab berfungsi sebagai rubrik kerja, bukan pengganti RPS.

## UTS

Case-based assessment 20%. Berikan kasus baru dan minta mahasiswa menganalisis sistem, interoperabilitas, arsitektur, data exchange, API, dan security mechanism. Hindari soal definisi saja.

## Project dan UAS

Nilai bukti proses, bukan hanya demo: design 20%, implementation 25%, security 15%, testing 15%, documentation 10%, presentation 15%. UAS mengukur kemampuan mempertanggungjawabkan keputusan desain dan keterbatasan solusi.

## Pemeriksaan luaran

Pastikan repository dapat dijalankan, contract konsisten dengan implementasi, test memiliki positive dan negative case, serta README menjelaskan setup dan batasan sistem.
