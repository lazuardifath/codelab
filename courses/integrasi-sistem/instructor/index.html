Panduan Dosen

Gunakan course sebagai learning journey: Learn → Understand → Analyze → Design → Build → Test → Evaluate.

Fokus pengajaran

Modul 1–8 membangun fondasi dan desain; Modul 9–12 membahas pola komunikasi dan orchestration; Modul 13–16 mengarah ke implementasi, reliability, testing, dan final project.

Pertanyaan pemantik

  • Sistem mana yang menjadi sumber kebenaran?
  • Apa yang terjadi jika Payment Service timeout?
  • Bukti apa yang menunjukkan integrasi benar-benar bekerja?

Penilaian

Nilai keterlacakan requirement → architecture → contract/schema → implementation → test evidence. Detail rubrik tersedia pada dokumen pengajaran repository.
