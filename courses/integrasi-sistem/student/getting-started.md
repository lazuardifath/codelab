# Getting Started

1. Buka course Integrasi Sistem dari katalog.
2. Kerjakan modul secara berurutan.
3. Gunakan server lokal: `py -m http.server 8000`.
4. Simpan setiap artefak dalam repository Git kelompok/individu.
5. Centang checklist setelah bukti pekerjaan selesai, bukan sekadar setelah membaca.
