# Learning Path

Setiap modul mengikuti pola: konsep → contoh → praktik terbimbing → experiment → challenge → refleksi. Bawa artefak ke modul berikutnya. Jika ada perubahan, dokumentasikan alasan dan commit Git-nya.

Urutan milestone: problem, requirement, architecture, data mapping, API, security, implementation, reliability, testing, final system.
