# Project Guide

Bangun Integrated Campus System sebagai satu cerita repository yang berevolusi, bukan project baru setiap minggu. Gunakan urutan versi berikut:

```text
v01 Student Service
  → v02 Payment Service
  → v03 REST API
  → v04 Sanctum authentication
  → v05 Queue dan async
  → v06 Event-driven
  → v07 Integration Layer
  → v08 Error handling dan logging
  → v09 Integration testing
  → v10 Final Integrated System
```

Core yang wajib: PHP 8.3, Laravel 12, MySQL/MariaDB, REST API, JSON, Postman, Git/GitHub, Sanctum, Queue, Events, logging, dan PHPUnit/Pest. Redis, RabbitMQ, Docker, API Gateway, OAuth 2.0, Kong, Traefik, OpenAPI, dan Telescope digunakan sebagai pengayaan sesuai kesiapan kelompok.

Jangan menunggu modul 16 untuk mulai coding. Setiap milestone harus tersimpan di Git dan dapat dijelaskan saat demo.
