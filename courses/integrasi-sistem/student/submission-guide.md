# Submission Guide

Kumpulkan repository, API documentation, diagram, data mapping, Postman collection, test report, README, dan demo sesuai instruksi dosen. Sertakan screenshot/evidence yang menunjukkan request, response, log, dan hasil pengujian.

AI boleh digunakan untuk brainstorming, memahami konsep, atau debugging. Mahasiswa tetap wajib memahami dan dapat menjelaskan seluruh artefak yang dikumpulkan serta mengikuti aturan sitasi dan academic integrity.
