# Modul 03 — Navigasi dan Pengelolaan State

Modul ini adalah guided lab lengkap untuk membangun aplikasi **UNIMUGO Event** menggunakan Flutter, GoRouter, dan Riverpod.

## Capaian

- Membedakan Navigator stack dan router deklaratif.
- Menerapkan route daftar-detail dengan GoRouter.
- Menjelaskan alasan state management pada aplikasi yang bertumbuh.
- Memodelkan loading, error, success, dan empty state.
- Menguji route, parameter, retry, dan back navigation.

## Alur project

`Model → Repository → State/Provider → Page → Router → Test → Tugas`

## Menjalankan project

```bash
flutter pub add go_router
flutter pub add flutter_riverpod
dart format lib test
flutter analyze
flutter run -d chrome
```

Ikuti tutorial pada `index.html` secara berurutan. Jangan melewati checkpoint sebelum daftar, detail, state, dan route dapat diuji.

## Luaran tugas

Repository Flutter, fitur pencarian, route tambahan, loading/error/success/empty state, minimal satu test, README, screenshot, video demo, dan refleksi.
