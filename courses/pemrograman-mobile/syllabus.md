# Rencana Pembelajaran Pemrograman Mobile

**Program Studi:** S1 Teknologi Informasi, Universitas Muhammadiyah Gombong  
**Bentuk:** Praktikum berbasis proyek  
**Status:** Aktif · versi 1.0

## Ruang lingkup

Materi membahas fondasi Flutter dan Dart, antarmuka deklaratif, layout responsif, navigasi, state management, konsumsi API, penyimpanan lokal, pengujian, keamanan, dan deployment. Modul dapat digunakan secara berurutan, tetapi dosen dapat memilih modul sesuai RPS.

## Modul tersedia

1. Fondasi Flutter dan kesiapan environment
2. UI deklaratif dan desain responsif
3. Navigasi dan pengelolaan state

Modul lanjutan tentang API, persistence, testing, CI/CD, dan keamanan disusun pada tahap pengembangan berikutnya.
