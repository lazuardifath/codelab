Panduan Dosen

Panduan merancang, menguji, dan menerbitkan materi pembelajaran di UNIMUGO CodeLab.

Prinsip pembelajaran

Gunakan alur Context → Concept → Visualize → Guided Practice → Independent Practice → Reflection → Assessment.

Prioritas: kejelasan konsep, praktik yang dapat diperiksa, studi kasus konsisten, aksesibilitas, lalu visual.

Membuat modul

  1. Buat folder pada courses/nama-course/modules/.
  2. Tambahkan tujuan pembelajaran yang terukur.
  3. Mulai dari masalah, lalu konsep, visual, praktik, refleksi, dan assessment.
  4. Gunakan data-progress-check untuk checklist progress.
  5. Gunakan data-quiz dan data-correct="true" untuk quiz.
  6. Pastikan link modul sebelumnya dan berikutnya tersedia.

Praktik visual

Untuk tutorial aplikasi, letakkan ilustrasi dan instruksi di dalam codelab. Jangan menjadikan PDF atau situs berbahasa Inggris sebagai satu-satunya panduan. Berikan data input, expected output, dan troubleshooting.

Checklist QA

  • Tujuan, latihan, dan quiz selaras.
  • HTML valid dan tidak ada placeholder.
  • Link relatif tidak rusak.
  • Responsive di desktop dan mobile.
  • Diagram memiliki penjelasan atau text alternative.
  • Progress dan feedback dapat digunakan.
