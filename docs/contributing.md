# Kontribusi Materi

Kontribusi dosen dan tim pengembang dilakukan melalui branch terpisah atau pull request. Periksa hal berikut sebelum mengirim perubahan:

- tidak ada identitas, URL, analytics, atau branding pihak lain yang tertinggal;
- tautan relatif bekerja pada GitHub Pages;
- materi memiliki tujuan yang terukur dan output yang dapat diperiksa;
- source code konsisten dengan versi tools yang disebutkan;
- halaman nyaman dibaca pada desktop dan smartphone;
- atribusi sumber eksternal dipertahankan.
