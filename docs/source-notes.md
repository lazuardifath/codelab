# Catatan Analisis Materi Sumber

Repository awal berisi materi praktikum Flutter/Dart dari sumber eksternal. Konsep yang masih relevan dipertahankan secara selektif pada tiga modul awal: ekosistem Flutter dan setup, UI deklaratif/responsif, serta navigasi/state management.

Penyajian, studi kasus, struktur halaman, contoh data, dan source code pada modul baru ditulis ulang untuk konteks Program Studi S1 Teknologi Informasi UNIMUGO. Identitas, analytics, URL repository, dan branding sumber tidak digunakan pada platform publik.

**Status atribusi/lisensi materi sumber: [PERLU DIKONFIRMASI].** Sebelum distribusi resmi, pengelola perlu memastikan ketentuan lisensi materi asli dan menambahkan atribusi yang diwajibkan bila ada. Referensi teknologi pada modul diarahkan ke dokumentasi resmi masing-masing proyek.
